# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

Append-only; one line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. Capped at
50 lines and 20,000 bytes — when full, compress or prune rather than letting it
grow; git history keeps the full record.

- 2026-07-23 (M83): pinning a brms/engine fit to an explicit `type=` (or `level=`) in a test silently breaks that block's WHOLE-VECTOR `estimate == estimate` comparisons against paired glmmTMB/lme4/reference fits still at the default — the reference returns all four formulations (or both levels) while the pinned fit returns a subset, so lengths mismatch, or R recycles the shorter into the longer and `all()` passes by luck. - 2026-07-23 (M84): extending a variance-stabilized transformed bootstrap-t from balanced to unbalanced, studentize the pivot the IJ SE is DERIVED for (`theta = log SSA − log SSE`), NOT `log F` — they diverge under imbalance because a whole-subject resample changes total `N*` and hence the df-constant `C = log{(N−k)/(k−1)}` separating them; on balanced data `N*` is fixed, `C` invariant, and they coincide (why the M75 balanced code got away with `log F`). The eq. 7 / Appendix-A IJ SE influence value already carries `n_i`, so the SE formula itself is the general form — only the pivot and the transform's group-size constant (`n0`, ohyama eq. 3, not the harmonic mean) need the unbalanced treatment.
