# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

Append-only; one line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. Capped at
50 lines and 20,000 bytes — when full, compress or prune; git keeps the record.

- 2026-07-23 (M84): extending a variance-stabilized transformed bootstrap-t from balanced to unbalanced, studentize the pivot the IJ SE is DERIVED for (`theta = log SSA − log SSE`), NOT `log F` — they diverge under imbalance because a whole-subject resample changes total `N*` and hence the df-constant `C = log{(N−k)/(k−1)}` separating them; on balanced data `N*` is fixed and they coincide (why M75's `log F` got away with it). The eq. 7 IJ SE already carries `n_i`, so only the pivot and the transform's group-size constant (`n0`, ohyama eq. 3, not the harmonic mean) need the unbalanced treatment.

- 2026-07-24 (M88): calibrating a per-geometry constant like MPL's κ_m — the argmax over the (ρ,δ) grid is NOT fixed at the (min ρ, max δ) corner across geometries (it moves interior at R=2 and R≥8), so a corner-direct evaluation under-estimates κ_m (→ narrower interval → under-coverage).
