# M156: Plain-English pass over the condition text, and NEWS under R7/R8

**Status:** done (2026-09-24, PR #174 https://github.com/jmgirard/intraclass/pull/174)

**Goal:** Bring the text of every condition the package raises, and `NEWS.md`, under the house prose rules of `cairn/doctrine/prose-style.md`.

**Outcome:** Every error, warning, note, `check_installed()` reason and `R/boundary-hint.R` hint bullet now has no dash as punctuation and no sentence over 25 words. Semicolon joins are split, except between references. Which condition fires, its class and its fields are unchanged. The new hand-run ruler `data-raw/condition-text-profile.R` assembles each message from its call site with `getParseData()`, with the hint bullets from the builders. It counts R1, R2 and R8, and `--compare-tokens <ref>` compares the code around the messages. At merge it reports 208 sites, R1 0, R2 0 and R8 0, with 0 token differences against `main`. The hint bullets now open "was run on your data and returns an interval where X cannot". The `ac5_expected` pin in `test-reducer-abort-hint.R`, one `bayesian-vignette-oracle.rds` warning field and the `engines.Rmd` pasted warning were re-frozen. `NEWS.md` glosses every first-use glossary term verbatim and has a Documentation bullet for the rewording. The doctrine scope paragraph names condition text under R1–R6 and R8, gives the R7 reason and names the ruler (119 lines, 7,133 bytes).

**Decisions:** a new R ruler instead of a condition-text mode in `prose-profile.py`, because the hint bullets need R to run the builders. Condition text is excluded from R7. The printed `choose_icc()` and `summary()` text went to a candidate row. None were promoted to DECISIONS.md.
