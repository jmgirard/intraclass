# M141: The `n_o` disposition grid is pinned, and the fixed-rater replicate abort names the right condition

**Status:** done (2026-08-27, PR #152 https://github.com/jmgirard/intraclass/pull/152)

**Goal:** Put every disposition of `icc()`'s within-cell-replicate dispatch under a standing grid test, and correct the two records that misstate it — one abort message, one `DECISIONS.md` clause.

**Outcome:** `tests/testthat/test-n-o-disposition-grid.R` generates 42 cases with `expand.grid()` over five axes (`multilevel`, `ml_design`, `raters`, whether `level` carries `"conflated"`, replicate shape), joins each to its expectation by axis values with set equality asserted both ways, and declares per case the `glance()$n_o` value, the abort message substring, and the whole condition set signalled ahead of either — 195 expectations, every one measured by executing `icc()`. A branch-count assertion locates the dispatch block inside `deparse(body(icc))` by its own code strings, through the block's closing brace, and equates the `abort_` calls there against the distinct branches the grid names; it carries `skip_on_covr()`, since `covr` rewrites the body. The fixed-rater replicate abort (`R/icc.R`) now opens "Ragged or incomplete within-cell replicates are not supported for fixed raters yet.", mirroring its multilevel sibling, and both `i =` hints name the missing-cell shape beside the unequal-count one; the block comment above it, which called the shipped scope "BALANCED only", now says balanced-and-complete. Nothing the package computes changed.

**Decisions:** D-041 — `glance()$n_o` is `NA` on a replicated design missing a cell it defines, not only on a ragged one; supersedes D-038 clause 2's enumeration, D-038 unedited.
