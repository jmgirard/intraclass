# M138: Exported-schema remainder — `glance()` gains a rater accessor before the one-way door closes

**Status:** done (2026-08-26, PR #148 https://github.com/jmgirard/intraclass/pull/148)

**Goal:** Land the three exported-schema corrections descoped from M48 while GP2's one-way door is still open, so no post-submission change to `glance()` or `tidy()` needs a deprecation cycle.

**Outcome:** `glance.icc()` gains two columns beside `balanced` (`R/icc-methods.R`): `raters`, the fit's rater treatment, `NA_character_` when `x$design$model` is `"oneway"`; and `replicates`, `isTRUE(x$design$replicates)` — reported in its own right because `n_o` beside it is `NA` on a ragged replicate design too, so replicate status is not recoverable from that column. The `glance()` name set is now identical across the five design families (one-way, two-way random, two-way fixed, multilevel, replicate), 24 columns, so any two rows bind. `tidy()$occasions` is `double` on every fit and every projection: `as.numeric()` on `tidy.icc()`'s replicate branch, `NA_real_` on its other branch, `as.numeric(row_occ)` at the projection's `add_column()` (the site an integer `n_o` reached uncoerced) and `NA_real_` at the projection fill (`R/d-study.R:524`, `:704`) — chosen over an integer column because `validate_n_o()` allows a non-integer occasion count and `as.integer()` would report a projected 1.5 as 1. `d_study()`'s `icc_raters` attribute is `NA_character_` on a one-way fit, keyed on `oneway` and not `ml_oneway`, so a projection's `glance()$raters` reads as the fit's does; `icc_design_phrase()` gained an `is.na(raters)` guard so the legacy-object fallback in `format.icc_dstudy()` cannot return `character(0)` if reached. Design 3 (`ml_design = "nested_in_subjects"`) deliberately keeps its nominal `"random"`, matching the sibling `type` column's convention there → candidate row. `?icc` no longer claims `tidy()`/`glance()` return the same information as the object. Refused: a `type` column on `glance()`, and freezing the column *order* as contract.

**Decisions:** D-038 (what `glance()` gained, why `type` was refused, why column order is not contract). Milestone-local: the `NA_character_` predicate is `model = "oneway"` alone rather than "every design with no rater facet", because widening `raters` alone would split it from the sibling `type` column's convention on Design 3.
