# M91: Export conf_level ∈ {0.90, 0.99} for ci_method = "mpl"

**Status:** done (2026-07-25, PR #98 https://github.com/jmgirard/intraclass/pull/98)

**Goal:** Enable `icc(..., ci_method = "mpl", conf_level = c)` for c ∈ {0.90, 0.99} to return a validated two-way random ICC(A,1)/ICC(A,k)/ICC(A,m) interval, extending the shipped 0.95-only support to the M90-calibrated levels.

**Outcome:** `conf_level` is now a **KEY** on the internal `kappa_m_table`, not an argument to a 0.95 constant: 162 rows (3 levels × 54 (R,S) nodes), assembled by `data-raw/m91-mpl-kappa-sysdata.R` from committed fixtures — 0.95 verbatim from `m88-kappa-table.rds`, 0.90/0.99 from `m90-kappa-tables.rds`, **raw calibrated values, deliberately un-smoothed** so each traces to the run whose coverage was validated (an envelope/smoother was chosen against at the plan gate → candidate). `mpl_kappa_lookup(n_r, n_s, conf_level)` interpolates linearly in S **within a level's slice only**; `icc()`'s fence derives its level set from the table itself and aborts otherwise (classed `intraclass_unsupported`, message names the set), so D-017's no-deeper-than-0.99 boundary is enforced by the table's contents plus a level-set pin in the tests. 0.95 endpoints are bit-identical (slice `identical()` to M88's). New: `data-raw/m91-mpl-interp-sweep.R` → `m91-interp-sweep.rds`, four pre-registered cells (frozen pre-run, GP5) closing the interpolated-S gap M90 left — D1 0.9340@0.90, D2 0.9995@0.99, D3 1.0000@0.99 (R=2, S=40, across the −0.154 dip), D4 0.9960@0.95 (sub-grid-floor ρ=0.02, closing RR03 rec-#9). **Interpolated S stays unprobed at 0.95** — every 0.95 cell sits on a node — stated in-code and filed as a candidate, not overclaimed. Docs record the level set, the interval's non-equal-tailed character (D1 misses 65/1), and the near-vacuous 0.99 width (D3 median 0.905, the corpus's only cell over the BC6 trigger); the `R/ci-mpl.R` interpolation comment is **corrected**, not softened — the table is non-monotone in S at every level (worst step −0.046/−0.068/−0.162), so linear interpolation is not conservatively biased. Also neutralized M88's stale `use_data()` call, which would have overwritten `sysdata.rda` with its pre-M91 3-column schema.
