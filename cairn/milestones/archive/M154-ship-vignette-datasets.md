# M154: Ship the vignettes' simulated datasets from `data-raw/`

**Status:** done (2026-09-17, PR #172 https://github.com/jmgirard/intraclass/pull/172)

**Goal:** Move every data simulation out of the articles and the README into one seeded `data-raw/` script whose output ships as package datasets.

**Outcome:** Four simulated datasets ship in `data/`: `school` (16 classrooms x 5 pupils x 4 raters, 320 rows), `school_incomplete` (a fifth of those rows dropped, 256), `ratings_replicates` (20 x 4 x 3 occasions, 240) and `ratings_twoway` (20 x 4, 80). The `ml-data`, `ml-incomplete-data`, `replicates-data` and `ci-mpl` chunks and the README `multilevel` chunk load the shipped objects; `test-vignette-claims.R` reads them in place of seven inline rebuilds (the M132 [O]-11 candidate row, absorbed). Four pages in `R/data.R` with examples that `check()` runs, four `_pkgdown.yml` rows, one NEWS bullet. Every article figure is unchanged; the README's multilevel output is now the `school` result, with a sentence naming the boundary consistency rows.
