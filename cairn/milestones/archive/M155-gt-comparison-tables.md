**Status:** done (2026-09-17, PR #173 https://github.com/jmgirard/intraclass/pull/173)

**Goal:** Hide the vignette chunks that exist only to assemble a comparison table and render those tables with `gt`.

In *Choosing an ICC*, the wider-random-interval claim now covers only the agreement coefficients. NEWS has one bullet. The `roadmap-terminal-rows` row in `data-raw/record-claims.tsv` was refreshed because the M154 done pass had left it stale and red on main.
