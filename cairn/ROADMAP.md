## Candidates

- MPL `ci_method = "mpl"` **0.95 sub-grid-floor coverage backfill** — RR03/BC5 adds a ρ_true=0.02 (below the κ_m calibration grid's ρ_L=0.05 fence) sweep cell at 0.90/0.99; the same exposure exists un-swept for the *shipped* 0.95 level. RR03 recommendation #9 (consider): a cheap 0.95 backfill cell in a later maintenance sweep would make the sub-grid-floor posture uniform across levels. If M90's C8 passes at 0.90/0.99 it substantially de-risks 0.95 by analogy. Low priority; promote via `/milestone-plan`. Lineage: RR03 → D-017.
- Re-run the seeded oracle scripts to re-establish **reproducibility**, starting with `data-raw/oracle-bayesian.R`. D-008 fixed the M72 bar at *provenance* — the registry agrees with what the repo commits — and explicitly refused re-running, so no entry currently claims that a script re-run today still produces its committed values (engine, BLAS and RNG drift are all unbudgeted). M72 T4 found the concrete motivation: O-Bayes' prose disagreed with its own committed fixture on every statistic, and no re-run could adjudicate which earlier run was authoritative because a fresh run yields a third set. Scope: regenerate per script, record an engine-version delta beside each fixture, and decide what a divergence from the committed values means before running (not after). The Bayesian sweeps are multi-hour live-Stan jobs ([[brms-coverage-oracle-is-a-background-job]]), so this is background work sized per script, not one milestone for all of them. Standing gap under PRINCIPLES.md #12. Promote via `/milestone-plan`. Lineage: D-008 → M72 T4.
- Acquire the one remaining off-shelf source cited by `ORACLES.md` and verify its leg — Cronbach et al. (1972), co-cited with Brennan (2001) for the two-facet decomposition behind O-Bayes-Rep. Low stakes, and lower now that Brennan is verified: the decomposition is standard GT, is independently pinned by that entry's own oracles, and its Brennan half is confirmed against Ch. 3 (printed pp. 56/58), so what is left is one half of a co-citation. The ask is the equivalent passage in Cronbach et al. — the crossed two-facet decomposition, or better the replicates-within-cell design O-Bayes-Rep actually fits. **Narrowed from four works to one across M72 T3:** `lee2024a` and `vispoel2022b` reached the shelf mid-milestone and closed two legs (the Vispoel leg's GENOVA mis-attribution corrected in passing), and `brennan2001_ch3` closed the Brennan half. Lineage: M72 T3.
- On-the-fly κ_m calibration for `ci_method = "mpl"` — the alternative to M88's precomputed table (D-015): calibrate κ_m at call time for the exact (R,S) geometry, exact but ~minutes and stochastic (needs a `seed`). Promote only on a concrete need for off-grid geometries the M88 table+interpolation doesn't serve. Lineage: D-014 (ii) → D-015 → M88.
- Classical **fallback-on-abort** default (MC aborts → classical closed-form interval) — the distinct `#3`/ADR-003 contract-change question D-012 explicitly fenced out of the opt-in track, and fenced again out of M82 at its plan gate. Unlike the opt-in `ci_method` (which only adds an option), replacing the default abort with a classical fallback changes the contract and needs its own every-cell replacement-grade assessment (Burch's wider non-normal battery — platykurtic + skewed, Table 2 — and larger ρ, per the D-012 scope fence). Promote via `/milestone-plan`. Lineage: D-006 → M76/D-012 → M82 plan gate.
- **Design-aware boundary-abort hint** — when the Monte-Carlo default aborts (`intraclass_singular_fit`) near the σ²→0 boundary, the classed error currently gives only generic remedies (refit / aggregate). Add a design-aware pointer to the boundary-robust opt-in `ci_method` for the design in hand: `"mpl"` for two-way random absolute agreement (returns an interval on 100 % of near-zero datasets where MC aborts 26–31 %, D-014), `"npbootstrap"` for one-way (D-006/D-010), the `"searle"`/`"burch"` closed forms where applicable (D-012/D-013). **Message/guidance only — NOT auto-routing or fallback** (that is the contract-changing candidate above, D-012-fenced); the default still aborts, it just names the exit. Must be design-aware — a blanket "try mpl" is wrong off two-way-random-agreement. Low-risk UX; scope includes which abort sites carry the hint (MC/bootstrap boundary aborts, not identifiability aborts). Promote via `/milestone-plan`. Lineage: 2026-07-24 conversation; sibling to the fallback-on-abort candidate (D-012).
