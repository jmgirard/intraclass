## Submission

This is an update from 0.1.0 to 0.2.0. It renames the result classes to
avoid a clash with the performance package. It also adds a method for
`parameters::model_parameters()` and four example datasets, and it fixes
several fitting and interval bugs. NEWS.md lists the changes.
